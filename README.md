# Trabalho 01 — Conversão de Expressões

Esta branch contém a solução do **Trabalho 01** da disciplina **Algoritmos 1**.  
O objetivo do trabalho é implementar, em linguagem C, um programa capaz de **converter expressões matemáticas entre diferentes notações**, conforme especificado no enunciado fornecido pelo professor.

---

## 📄 Arquivos do Trabalho

- **converte_expressao.c**  
  Arquivo fonte em C contendo a implementação da solução do trabalho.

- **t01.pdf**  
  Enunciado oficial do Trabalho 01, contendo a descrição do problema, regras, restrições e exemplos de entrada e saída.

---

## ⚙️ Compilação

Para compilar o programa, utilize um compilador compatível com o padrão C (como o `gcc`):

```bash
gcc -Wall -Wextra -std=c11 converte_expressao.c -o converte_expressao
```

---

## ▶️ Execução

Após a compilação, execute o programa com o comando:

```bash
./converte_expressao
```

A entrada e a saída do programa seguem exatamente o formato descrito no arquivo **t01.pdf**.

---

## 📌 Observações

- O código foi desenvolvido exclusivamente para fins acadêmicos.
- A solução segue as especificações e restrições apresentadas no enunciado.
- Recomenda-se a leitura do arquivo **t01.pdf** para o correto entendimento do problema e dos formatos de entrada e saída.
