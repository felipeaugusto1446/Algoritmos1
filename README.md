# Trabalho 02 — Labirinto

Esta branch contém a solução do **Trabalho 02** da disciplina **Algoritmos 1**.  
O objetivo do trabalho é implementar, em linguagem C, a resolução de um **problema de labirinto**, conforme especificado no enunciado fornecido pelo professor.

---

## 📄 Arquivos do Trabalho

- **labirinto.c**  
  Arquivo fonte em C contendo a implementação da solução do problema do labirinto.

- **t02.pdf**  
  Enunciado oficial do Trabalho 02, contendo a descrição completa do problema, regras, restrições e exemplos.

---

## ⚙️ Compilação

Para compilar o programa, utilize um compilador compatível com o padrão C (como o `gcc`):

```bash
gcc -Wall -Wextra -std=c11 labirinto.c -o labirinto
```

---

## ▶️ Execução

Após a compilação, execute o programa com o comando:

```bash
./labirinto
```

A entrada e a saída do programa seguem exatamente o formato descrito no arquivo **t02.pdf**.
